锦册 · Brocade Book

这套体系把书页交给第三方框架与组件：daisyUI 出组件与主题令牌，Tailwind 出原子排版， Alpine.js 出轻交互，highlight.js 出代码着色，Lucide 出图标。 设计以它们的原生形态与最佳阅读体验为第一要务；从素卷整组继承的只有可视化语义配色（§10）。 右上「主题」可换六款书籍气质主题，整页令牌随之翻转。

§1

总则与整合链

三个库各司其职、单向叠加：Tailwind 负责版式原子，daisyUI 在其上提供组件与令牌，Alpine 只做行为增强，hljs / Lucide 负责两种专业渲染。页面加载链如下——

  • Tailwind 4
  • daisyUI 令牌+组件
  • Alpine 行为层
  • hljs · Lucide
JC-1

组件优先。先在 daisyUI 组件清单里找（本页 §3「组件目录」逐一列出书籍允许的组件），找不到再用 Tailwind 原子类拼，仍然拼不出才写自定义结构。页面上每一块 UI 都要答得上「我来自哪个组件」。

JC-2

令牌驱动。颜色只从主题变量取（bg-base-100、text-primary……），软色用 color-mix() 从令牌派生；切换主题 = 更换令牌组，页面不许有任何一处颜色漏网。

JC-3

多主题同构。六款手调主题——素 / 缥 / 皓（日间）、玄 / 檀 / 宵（夜间）——共用同一 DOM 与间距，仅令牌不同（data-theme 键沿用 light / corporate / nord / dark / dim / night，兼容 ?theme= 深链与本地记忆）；调色板以 OKLCH 手调（§2 法度），hljs 按 color-scheme 自动跟浅深两套着色。主题选择本地记忆，未选时跟随系统。

JC-4

全本地、零构建。五个依赖以固定版本 vendored 在 assets/，页面只引相对路径；禁外链 CDN、禁 Node 构建链。判断标准：断网双击 framework/index.html，页面完整成立。

§2

主题与令牌

语义色七枚 + 中性阶三级构成全套令牌。六款主题的调色板以 OKLCH 手调、各以一味传统色定气质：素（暖纸靛青）、缥（天缥青碧）、皓（皓白藏青）为日间系，玄（玄墨琉璃）、檀（乌檀铜青）、宵（宵蓝星辉）为夜间系。法度：中性阶定纸墨、主色克制约减（彩度 ≤0.11）、语义色守色相并保足彩度供图内描边（彩度 ≥0.09，见 §10），跨主题亮度档对齐、软墨透明度分浅深两档保对比。下表为「素」与「玄」两组基准值，右上「主题」菜单可即时预览全部六款。

JC-5

语义即语义，不许挪用。error 只给真危险、success 只给真新增、secondary 只给外部系统；「想强调」用 primary 的字重与描边。同屏语义色（success / warning / error 合计）至多一枚。

JC-6

变体修饰符按档位使用。daisyUI 的 -soft / -outline / -dash 与 -sm / -md / -lg 是组件自带的强度与尺寸档位：旁注用 soft、中性用 outline、可丢弃示意用 dash；同一区块内档位保持一致，不混搭出噪声。

JC-7

圆角、边框、阴影走令牌与组件默认。rounded-box / rounded-field / rounded 三档按容器级差使用、同排展品同档；全页只许一种自定阴影——展品容器（表 / 图 / 代码 / diff）共用的 0 1px 2px 墨色 7% 发丝影（--jc-shadow，令牌派生）；玻璃效果只用 glass 工具类（顶栏），不另造阴影值。

JC-9

多文件 = tabs，单文件 = 卡。同一示例的多个文件进一张 tabs 卡（tabs-border + Alpine x-show），标签即文件名；单文件直接用代码卡。卡头三件套：文件名（等宽 13px）、语言标签、复制钮；复制成功用 toast 报告「已复制 hello.cpp」。

JC-10

着色整体外包给 hljs。github（浅系主题）/ github-dark（深系主题）两套样式随 color-scheme 自动切换，禁自定义配色；token 色归 hljs、代码纸底透明即主题纸面；代码体 14px / 1.65 等宽、长行横向滚动，不许缩字号换行。

JC-11

问题 / 修正用 diff 对照。两版代码放同坐标、同排版的满宽层里（diff-item 的直接子层必须 100cqi 满宽 + 不透明底，禁加 w-full——utilities 层会盖掉 daisy 的宽度规则）；左层 5% error 淡染、右层 5% success 淡染，改动行整行铺 12% 语义色条纹；行尾注释右对齐钉住面板右缘、两枚标签分别钉左端与右端，保证中缝停在任意位置两侧都有内容可读。两块除颜色与标记外逐像素一致，禁止在 diff 面板里各自居中摆小盒。

§5

提示框与微交互

五档语义映射 daisyUI alert；旁注级提示用 soft 变体降噪。微交互三件：tooltip 悬注、toast 反馈、kbd 按键提示。

note · 补充说明

默认档、最高频。中性纸色 + soft 变体，最安静。

info · 信息

客观事实与版本信息：「该特性自 CMake 3.20 起可用」。

success · 推荐

可直接照抄的结论性建议。

warning · 注意

易踩的坑与未定义行为。

danger · 危险

会造成实际损失的操作。

tooltip 悬注
tooltip
toast 反馈
kbd 按键 抽屉关闭 Esc
JC-12

五档映射固定。note → 中性纸色、info → alert-info、success → alert-success、warning → alert-warning、danger → alert-error；正文提示一律加 alert-soft 降噪，强提醒才用实底。图标 Lucide 五款（pencil / info / check / triangle-alert / octagon-x）永不混用。相邻两框独立成框。

JC-13

彩色同屏 ≤1，微交互不喧宾。success / warning / error 每屏合计至多一枚；toast 只报告动作结果（已复制 / 已展开），1.6s 自动退场；tooltip 只装一行字，不装段落。

JC-24

白底全彩描边，颜色只表义（自素卷 PB-30 整组继承）。框内不加底色、边框本身上色；只染边框不染文字——图内文字与箭头永远墨色；单图辅色 ≤2 主色相 + primary 焦点；中性状态（预留 / 未指定 / 机制内正常释放）用灰虚线，不许为好看把中性染成语义色。与素卷的差异仅在：辅色改由主题令牌派生（error / success / secondary），随主题翻转。

JC-26

§11

无 JS 与离线

禁用 JavaScript 后：目录抽屉仍可开合（复选框）、tabs 降级为首帧内容、全部文字可读、答案可展开；Alpine 只增强复制反馈、Esc 与大纲轨跟随。断网后：五个依赖 + 36 主题本地内置，页面完整成立。渐进增强的加载态由骨架组件表达——

skeleton · 骨架占位

loading · 过程指示

构建 / 校验进行中的瞬时状态
JC-27

JS 是增强不是依赖。内容开关一律平台原生（checkbox 抽屉、details 折叠、dialog modal、diff 拖拽）；骨架与 loading 只表达「即将出现的内容」，不用来表达状态机。

§12

自检清单

  • 断网双击打开页面完整成立；禁 JS 后抽屉可开、内容全可读
  • 颜色零裸值：页面与自定义 CSS 无 #hex / rgb(，全部主题令牌或其 color-mix 派生
  • 六款主题逐一点过：结构间距逐像素同构，hljs 浅深正确跟随
