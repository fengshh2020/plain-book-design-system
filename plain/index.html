PLAIN BOOK v1.0 · 单文件规范 · 本页即活样张

素卷 · Plain Book

一本给程序员读的 C++ 书，在 1280px 量级的屏幕上长读。本文件即规范：页面上看到的一切，就是书籍页面得到的一切——规范正文与书籍 assets/style.css 逐字同源。

0设计立场

素卷把书页当文档站设计——工程师每天读的 MDN / GitHub Docs 那种安静样子。书页不是礼仪品：没有进度条、没有章节下拉、没有深墨代码浮版，没有印章与题花——页面上出现的每一个元件都必须有职能，层次只来自字阶、间距与发丝线。

原则一

零装饰。层次只来自字阶、间距、发丝线。印章、描金、题花、进度条、圆点、圆环返回钮——一切无职能的元件都不许出现。

原则二

单栏独占，导航按需。正文单栏居中、独占全屏——阅读时零干扰。导航恰有两条：全书导航收进顶部「目录」按钮唤出的抽屉（书 → 章 → 节三级），答「往哪跳」；宽屏（≥1360px）右侧常驻「本页」大纲细轨、滚动跟随，答「读到哪了」。其余一切导航形式禁止。

原则三

代码属于纸面。浅底细框（GitHub-light 系），绝不在白纸长文里嵌深色浮版——深浅反复切换造成的眩光泵动，是长读疲劳的第一根源。

1色彩

近单色墨系 + 一个静墨蓝。页面 95% 的面积是纸与墨；蓝只出现在链接、节号、激活态三处。语义三色只进状态组件，绝不参与装饰。下表为纸面取值；墨版整组翻转见 PB-31。

PB-1

裸值只允许出现在 :root；组件一律 var(--token)。

PB-2

静墨蓝只给三处：正文链接、.h-num 节号、目录激活态。版面占比 ≤5%；再想要颜色时，用字重和间距解决。

PB-3

success / warning / danger 只出现在提示框与答案正误对照里；正文、表格、插图一律不用语义色。

PB-4

代码配色固定 GitHub-light 语义（关键字绯红、字符串藏蓝、数字湛蓝、注释灰斜体、函数紫），不自创花色——程序员对这套色的肌肉记忆就是协调本身。

PB-31

墨版：整页翻转，绝不混排。深灰纸面（#171B20 级，不用纯黑）+ 米白墨字（#E2E6EA 级，不用纯白），防光晕、护长读；静墨蓝提亮一档保链接对比；代码与纸面同底，配色切 GitHub-dark 语义；图内语义描边同步提亮。默认跟随系统、手动切换即记忆，打印永远纸面。浅页里嵌深色代码板不是墨版，是眩光泵动——禁止。

2字阶与间距

7 级字阶、4 档间距，全部锁死。中文正文 17px / 1.8；文字列 720px 约 42 字/行，代码 / 表格 / 插图等组件占 840px 组件版心。

令牌值用途
--fs-30036px / 600章题（每章一枚）
--fs-25026px / 600h2 节题，下发丝线
--fs-20020px / 600h3，左侧蓝色记号条
--fs-15017px / 1.8正文、h4
--fs-12515px导语、翻页器、按钮、顶栏书名
--fs-10014px表格、提示框、代码、目录按钮
--fs-7513pxkicker、题注、图例、元信息
PB-5

间距近小远大四档：同族块 12px（li 之间）、段落 14px、段落与组件 24px、节与节 64px。禁止发明第五档。

PB-6

行内代码是中性浅灰片（#EFF2F4，86% 等宽）：不用品牌色、不加圆点、不上边框——它出现频率极高，必须安静。

PB-7

等宽字体只给代码、文件名、命令、kicker、题注等技术内容；中文正文永远黑体，全站不用衬线。中文段落与列表两端对齐（justify，方块字对齐后边缘整齐），标题、表题、封面简介、提示框保持左对齐或居中——窄容器不 justify。中文排印细则：强调与标题字重一律 600，配 font-synthesis:none 防 CJK 合成粗体发糊；避头尾用 line-break:strict；中西文间距交给 text-autospace 渐进增强，不手工插空格；标题 text-wrap:balance、正文 text-wrap:pretty；中文标题字距为 0，不用负值。

PB-8

顶栏只放四样：目录按钮（发丝描边胶囊 + 三横线图标）、书名（链接回封面）、当前章（13px 灰，如 CH.01 · 编译与开发环境）、主题切换钮（月亮 / 太阳图标，纸面 ↔ 墨版）。≤760px 时当前章隐藏。抽屉常驻三级导航：书名 → 部分组标签 + 章链接 → 当前章的节目录；当前章高亮 --accent-soft 底，当前节滚动跟随（.cur）。抽屉永不放假装饰。

PB-9

正文单栏双档版心：正文 / 列表 / 引用落在 720px 文字列（17px 下约 42 字/行），代码 / 表格 / 插图 / 提示框等组件占 840px 组件版心，两档左缘对齐、只向右延展。桌面（--desk）与白纸页（.prose：白底 + 四边 1px 发丝框 + 一道 1px 气口投影）构成第一层图底关系，顶栏与桌面同色、纸页浮于其上；顶栏内距、翻页器、页脚与纸页同宽对齐，形成一条看得见的版心。

PB-10

抽屉开关四条通路都要有：按钮开合、右上 ✕、点遮罩、Esc；抽屉内任一链接被点击后自动关闭。禁用清单：进度条、章节下拉、悬浮章指示器、印章、描金、题花、装饰圆点、圆环返回钮、drop cap、卡片阴影堆叠。返回顶部保留但仅为 40px 发丝圆钮，滚过 640px 才出现。

PB-11

锚点定位用 html{scroll-padding-top:70px} 为 sticky 顶栏留位，不写 JS 补偿。≤760px 正文内距收到 20px；打印时顶栏、抽屉、遮罩、交互件全部退场。

PB-32

宽屏（≥1360px）常驻右侧「本页」大纲细轨：13px、176px 宽、左缘 2px 线，当前节滚动跟随（.cur 蓝字蓝线）；窄屏自动退场，导航交回抽屉。无 JS 时它是普通锚点列表，仍然可用。除抽屉与本轨外，不设第三种导航。

4章头与节奏

章头三级：kicker（等宽小字 CH.01 · 第一部分 · 入门与基础）→ 章题 36px → 导语至多两段（15px 次级色）。第 3 段起降为正文字号留在章头内，内容不删、字号降级。

PB-12

每个 h2 是一节：节号 .h-num 静墨蓝等宽 + 节题 26px + 底部 1px 发丝线。发丝线是节与内容块之间唯一的分隔装置。

PB-13

h3 前距 40px 且左侧带 3px 静墨蓝记号条（与灰色引用竖线拉开）、h4 前距 28px，后距一律 10–12px：标题与其内容绑定，与上一块疏离。有序列表序号着蓝（ol > li::marker），无序列表圆点保持灰。

PB-14

章节互引（如「第十二章」）用正文链接色自动连接，不做任何特殊徽标。

5代码

hello.cppcpp
#include <iostream>
int main() {
    std::cout << "Hello, 素卷!"<< '\n';  // 代码属于纸面
    return 0;
}
PB-15

代码永远属于纸面：白底（--code-bg #FFFFFF）+ 1px --code-line 细框 + 10px 圆角，与纸面只隔一道描边。禁止灰底/深底代码板，禁止投影、青光、内描边。

PB-16

代码头为 --paper-2 洗色栏 + 发丝下缘，与白底代码形成块内层次；只保留三样有职能的元件：文件名（等宽 13px 墨色）、语言标签（11px 大写灰，右对齐）、复制钮（点击后「已复制」1.6s）。不使用 macOS 窗口圆点。

PB-17

代码正文 14px / 1.7 / 4 空格 tab；长行横向滚动，不许缩字号换行。

PB-28

代码卡必须有名字。每个围栏都写 caption="…"，代码头名称槽不许空着——空名卡在评审里视同缺陷。命名规约：练习节 练习 {ch}-{q} · 问题代码 / 答案示例（多块加（二）（三））；主流程按类目前缀——终端命令 命令行 · …、程序输出 程序输出 · …、语言对照 Python 对照 · …，其余 cpp 块按语义起名。构建前无名围栏扫描必须归零。

6提示框

一律是软色卡片：整框 1px 同色系描边 + 5–8% 淡染底 + 图标与彩色标题，框内正文永远墨色。图标统一为「同色 10% 淡染圆角衬底 + 14px 描边图标」：note 铅笔、info 圆-i、success 对勾、warning 圆角三角、danger 八角止步——五档图形语义分明，永不混用文字当图标。五档分工——note 是高频「栏目型」，灰底灰线最安静；info 客观事实，蓝卡；success / warning / danger 是真状态，各自语义色卡。旁注同样是完整的盒子：描边与淡染缺一不可。

note · 补充说明默认档。放「顺带一提」的背景与延伸，灰卡灰线——出现频率最高的框必须最安静。
info · 信息客观事实与版本信息：「该特性自 CMake 3.20 起可用」。蓝卡。
success · 推荐可直接照抄的结论性建议。绿卡。
warning · 注意易踩的坑与未定义行为。琥珀卡。
danger · 危险会造成实际损失的操作。红卡。
PB-18

同屏彩色提示框（success / warning / danger 合计）至多一个；要强调第二处，改写正文加 strong。

PB-19

提示框字号 14px / 1.75，比正文小一号——它是旁注，不是正文的一等公民。淡染底 5–8%、描边同色 26–30% 透明度，饱和度再高就越权成广告了。

PB-29

提示框标题两种写法，相邻框必须独立成框。标题行写 > **[类型]** 或 > **[类型] 副题**（副题并入标题行，显示为「类型 · 副题」）。两个提示框之间无论隔空行、> 独行还是直接换行，构建器都必须切成两框——吞并在页面上的表征就是正文里出现字面的加粗方括号伪标题，见到即缺陷。另：章首提示框的正文段落不参与导语抽取——章头按顶层块（div 深度配对）切分，不许把框内 <p> 当导语剥走。

PB-20

表上图下。题注由 **表：题注** 行生成（表 N-M · 题注），居中放在框上方、间距 10px；细框圆角容器 + --paper-2 表头 + 行发丝线，无竖线。偶数行铺 55% paper-2 细斑马纹，悬停洗 45% accent-soft，数字列等宽对齐。提示框 / 术语框 / 答案里的内层表格走同一编号器，按文档顺序计数——嵌套不重排。

PB-21

插图一律 SVG 线框（上表分型），图内文字不小于 13px。文字宽度按实测字腔计量（西文等宽 7.7px/字、CJK 14px/字、黑体西文 7.9px/字，向上取 4 的倍数），节点与标签盒随文字自适应——禁止手写 w= 把字压出框。图例沉底横条、覆盖图中每一种分型、总宽超画布即构建报错、整体水平居中；题注 13px 灰、居中。SVG 必须带原生 width/height（D-13 铁律保留）。

PB-22

连线七则（借鉴 diagram-design）：① 不同轴节点连线一律正交肘线 + r=8 圆角，共轴才许直线，斜线打回；② 边标签离线 6–10px、衬不透明 .dg-mask 遮罩，遮罩不得压后画的节点——文字会碎成片段；③ 两条连线不共享路径、不上下压线，交叉处用跳线桥；④ 同一节点同一缘多线进出，挂点间距 ≥12px、平行线全程 ≥12px；⑤ 连线不穿非端点节点，几何上避不开的过境段必须虚线（.dg-edge-opt）；⑥ 箭头只落在真实终点，路过即无箭头；⑦ 走线与相邻文字（节点名、行标注等非边标签文字）外沿净距 ≥8px——2px 的擦边在 100% 缩放下读作压字（ch13 继承内存图实测翻车）。七则连同文字溢出、节点互叠、图例超宽、贴边一起在构建期由 render() 校验——报错即改，带病图进不了书。

PB-30

图内语义配色：白底全彩描边，颜色只表义。三辅色——--dg-bad #CF222E 正红（失效 / 悬垂 / UB / 数据丢失）、--dg-new #2DA44E 亮绿（新分配 / 新增成员）、--dg-ext #8250DF 紫（外部系统 / 语言对照）。着色方式：框内不加底色，边框本身上色（节点 1.4px、签牌 1.2px、危险路径 1.4px 虚线），白底上全彩描边即醒目又不糊版面。五条军规：① 只染边框不染文字——图内文字永远墨色，箭头也保持墨色；② 框内一律白底，禁止语义底色淡染；③ 单图辅色 ≤2 主色相 + 蓝（focal），再多就退回墨色系；④ 灰虚线（opt）仍是中性语义（预留 / 未指定 / 过境 / 机制内正常释放）的正当表达——颜色是给真危险的，不许为好看把中性染成语义色；⑤ 图例如实分列每一种染色分型，构建期严格校验覆盖。

8折叠、翻页与封面

PB-23

练习答案用原生 details.answer：+ / – 前缀（等宽蓝），无边框底色变化，无 JS 依赖。

PB-24

术语定义 .defn：--paper-2 底细框卡，词头等宽 600，词性标签 11px 灰胶囊。

PB-25

翻页器与版心同宽、上缘发丝线；左右两侧 flex:1 等宽，.next 只用 text-align:right 对齐——禁用 margin-left:auto（它会吃掉自由空间让 flex:1 失效，把标题压成窄条）。无上一章时用 visibility:hidden 占位，且只隐藏直接子级。

PB-26

页脚一行：左书名右元信息（25 章 · 8 部分 · C++20 · 素卷 v1.0），上缘发丝线，无 ❦ 题花。

PB-27

封面 = 居中 hero（kicker + 52px 章题 + 简介 + 数据胶囊 + 双按钮）+ 8 部分卡片网格。卡片只用于封面与目录，正文里禁止再出现卡片。

9自检清单

每次改动后逐项过；任何一条不过就不算过。

  • 整页除链接 / 节号 / 激活态外无第二色相；同屏彩色提示框 ≤1
  • 没有灰底/深底代码板；所有代码块白底细框、GitHub-light 语义色
  • 没有进度条 / 下拉 / 悬浮指示器 / 印章 / 描金 / 题花 / 圆点
  • 顶部目录按钮可唤出抽屉：当前章高亮、当前节滚动跟随；✕ / 背景 / Esc / 选中链接即关闭
  • 墨版整页翻转：深灰纸面 + 米白墨字 + 代码同底（GitHub-dark 语义）；无浅深混排；打印永远纸面；默认跟随系统、手动切换即记忆
